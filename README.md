# ずっこけぬこサッカー

Canvasで動くミニゲームをStreamlitに埋め込んだWebアプリです。

## ローカル起動

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Streamlit Cloud

Streamlit Cloudでは、メインファイルに `streamlit_app.py` を指定してください。
